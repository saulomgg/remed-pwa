## `> whoami`

```bash
$ cat /dev/remed
Nome:   Reméd
Preço:  grátis
Foco:   gestão de medicamentos · alertas de dose · pedidos rápidos
Modo:   PWA instalável no celular e no computador
```

PWA moderno e fluido para **gestão inteligente de medicamentos**. Organize seus remédios, receba **alertas de dose com integração ao Google Agenda** e faça **pedidos rápidos pelo WhatsApp**.

---

## `> ls ./recursos`

| Recurso | Detalhes |
|---------|----------|
| 💊 **Gestão de medicamentos** | Mantenha seus remédios organizados num só lugar |
| ⏰ **Alertas de dose** | Lembretes integrados ao Google Agenda para não esquecer nenhum horário |
| 💬 **Pedidos pelo WhatsApp** | Peça reposição de forma rápida, direto do app |
| 📱 **Instalável** | Adicione à tela inicial e use como um app, no celular ou no computador |

> [!IMPORTANT]
> O Reméd é uma ferramenta de organização e não substitui a orientação de médicos ou farmacêuticos.

---

## `> ./iniciar`

```bash
1. Acesse   remed.github.io
2. Instale  menu do navegador → "Adicionar à tela inicial"
3. Use      cadastre seus medicamentos e ative os alertas
```
